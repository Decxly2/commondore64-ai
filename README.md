# Commodore 64 & AI-historia

En svensk informationswebbplats om Commodore 64, tidig spel-AI och jämförelser med moderna AI-modeller. Webbplatsen är byggd med HTML, CSS och JavaScript, med responsiv layout, sektionsnavigering, läsindikator, animerade faktaräknare och knappar för att kopiera ett citat och visa slumpade fakta.

**Publicerad webbplats:** https://commondore64-ai.vercel.app

## Öppna lokalt

1. Klona projektet eller ladda ned det via **Code → Download ZIP** på GitHub och packa upp filerna.
2. Öppna `index.html` i en modern webbläsare. Behåll `index.html`, `style.css` och `app.js` i samma mapp.

Projektet behöver ingen installation, byggprocess, API-nyckel eller backend. Typsnitten hämtas från Google Fonts och kräver internetanslutning; systemtypsnitt används som reserv. Webbläsaren kan begränsa kopiering till urklipp när sidan öppnas som en lokal fil.

## Filer

| Fil | Innehåll |
| --- | --- |
| `index.html` | Svenskt innehåll, sidans struktur, navigation och knappar. |
| `style.css` | Färger, typsnitt, responsiv layout och visuella effekter. |
| `app.js` | Stjärnfält, animerade räknare, sektionsmarkering, läsindikator, citatkopiering och faktaknapp. |

## Bidra

Öppna gärna en issue för fel eller förbättringsförslag. Beskriv vad som händer, vad du förväntade dig och vilken webbläsare du använder. Vid innehållsrättelser, länka till en källa som stödjer ändringen.

För kodändringar, håll varje pull request till en tydlig förbättring och förklara hur du kontrollerade den. Öppna sidan efter ändringen, kontrollera layouten på både smal och bred skärm och prova de funktioner som påverkas. Förslag som förbättrar tangentbordsanvändning, läsbarhet eller stöd för minskad rörelse är också välkomna.
